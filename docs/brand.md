# Datsumi brand

## Positioning

Datsumi is a modern, minimalist database client for developers working across database technologies inside VS Code. Its interface should feel focused, native and thoughtfully designed.

- Product name: **Datsumi**
- Marketplace display name: **Datsumi — Database Explorer**
- Descriptor: **Universal Database Explorer for VS Code**
- Slogan: **Every database. One workspace.**
- Closing line: **Less switching. More building.**

## Marketplace copy

A modern, unified database client for VS Code. Explore, query, and manage SQL and NoSQL databases without leaving your editor.

Datsumi brings your databases together in one clean workspace inside Visual Studio Code. Browse tables, documents, and keys; run SQL and JSON-based queries; inspect relationships; and manage connections using native editors and a focused results panel.

The supported engines and adapter-specific capabilities are listed in the README. The slogan expresses the product direction; technical descriptions must stay aligned with implemented support.

## Identity

The layered D combines an open geometric D with three horizontal segments. It represents different data systems brought into one workspace. Rounded stroke ends echo the supplied reference, while the open left edge and unequal segment lengths keep the silhouette distinctive. Use the mark without text inside the rounded square.

| Color      | Hex       | Use                            |
| ---------- | --------- | ------------------------------ |
| Midnight   | `#142326` | Primary icon background        |
| Soft mint  | `#A1E8CF` | Primary D outline              |
| Muted mint | `#63BBA8` | Primary horizontal segments    |
| Graphite   | `#1C3034` | D outline on light backgrounds |
| Deep teal  | `#2C867A` | Segments on light backgrounds  |
| Ivory      | `#F5F5F1` | Light icon background          |

Assets in `apps/extension/resources`:

- `datsumi.svg`: scalable primary midnight/mint logo.
- `datsumi-light.svg`: ivory/graphite/teal variant matching the reference direction.
- `datsumi.png`: 256 × 256 Marketplace icon derived from the primary SVG.
- `datsumi-activity.svg`: transparent 24 × 24 monochrome variant for VS Code's theme-controlled Activity Bar and view icons.

Keep generous clear space, retain the proportions, and avoid gradients, shadows or a database-cylinder motif in product branding. Use VS Code's own typography, colors and semantic database/table icons inside the application; reserve brand colors for the identity rather than overriding editor themes.
