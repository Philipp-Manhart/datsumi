# Support

Use the repository's GitHub issues for reproducible bugs and focused feature requests. Include synthetic data and **Datsumi: Copy Redacted Connection Diagnostics**. Never include tokens, passwords, private keys, customer exports or sensitive SQL.

For database authentication, roles, network routing or provider outages, consult the database/provider administrator. Datsumi supports a documented subset of each protocol, not every authentication mode or server deployment. See [the support matrix](docs/support-matrix.md) and [connection troubleshooting](docs/connection-troubleshooting.md).

Security reports follow [SECURITY.md](SECURITY.md), not public bug reports. The project currently has no paid support or response-time guarantee. Maintainers should enable GitHub private vulnerability reporting when making the repository public; if its reporting form is unavailable, request a private contact in an issue without describing the vulnerability or including exploit data.
